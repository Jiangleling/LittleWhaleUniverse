# LittleWhaleUniverse
This is an intelligent emotional diary APP, built-in generative dialogue chat psychological counseling AI, to provide you with professional psychological counseling, counseling, communication services. At the same time, built-in seven-day analysis function, you can see your mood trend, let AI better understand your life.
